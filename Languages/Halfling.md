# Rhulka - Halfling Tongue of the Forest Ridge

Rhulka is the living speech of Athasian halflings. It is not only spoken with the mouth. It uses breath, whistles, bird-calls, throat sounds, hand signs, posture, eye contact, and mimicry of the jungle.

To outsiders, Rhulka sounds like birds warning one another, frogs calling from dark water, insects moving under leaves, and hunters speaking through breath.

Rhulka uses soft jungle sounds, sharp warning calls, and repeated natural rhythms.

Common sounds:

| Sound | Feel |
| --- | --- |
| **hu, huu** | kin, breath, belonging |
| **nha, nhae, nhaa** | water, rain, wetness |
| **fii, ui, chaa, kraa** | birds, distance, warning |
| **tik, trr, chrr, kiki** | insects, small things, swarms |
| **sii, shaa, lishi** | trails, leaves, wind |
| **ghu, nala, ruma** | roots, trees, home |
| **rau, ka, kara, akka** | meat, tooth, danger, hunt |
| **owa, shii, eya** | memory, spirits, dreams |

It is not “primitive.” That is important. It only sounds animalistic because halflings do not separate language from the living world. A bird-call, a branch-tap, a breath pattern, a hand sign, and a facial expression can all be part of one sentence.

## Sound palette

Use these sounds:

**Short phrases** = whistles and clicks of the tongue.
**Threats** = bird-like caws and sharp shrieks.
**Ritual speech** = low hoots and breathy repetition.
**Names** = musical, usually two or three syllables.

Example:

> **Huu-kiri sii.**
> “Kin, stay hidden.”

Said aloud, it should feel like:
**hoo-KEE-ree see-ee**

## It is tonal

The same syllable can mean different things depending on pitch.

Example:

| Sound | Low tone | High tone |
| --- | --- | --- |
| **ka** | tooth / bite | danger |
| **hu** | kin / tribe | spirit |
| **sii** | path | far / beyond |
| **tik** | small thing | many small things |
| **rao** | blood | grief |

This means outsiders can “know the words” and still misunderstand everything.

## It uses body language

A halfling sentence is incomplete without posture.

Example:

**ka-rau** can mean:

| Spoken with... | Meaning |
| --- | --- |
| open hands | “meat shared” |
| closed hands | “meat claimed” |
| eyes lowered | “the dead are honored” |
| teeth shown | “you are meat” |

Halflings rely heavily on shared culture for communication and become frustrated when outsiders lack that cultural context.

## It imitates the environment

A halfling can say “danger” in many ways, depending on what kind of danger.

| Rhulka sound | Literal sound | Meaning |
| --- | --- | --- |
| **kraa-kraa** | carrion bird call | death nearby |
| **tik-tik-tik** | insect chatter | many small enemies |
| **hrr-ow** | stalking beast growl | large predator |
| **sii-fii-sii** | wind through leaves | move silently |
| **krii!** | alarm bird shriek | immediate danger |

# Core Word Order

Basic Rhulka word order is:

**Subject - Action - Object - Place**

Examples:

| Rhulka | Meaning |
| --- | --- |
| **Huka chaka rau lishi.** | The halfling hunts meat in the leaves. |
| **Saru sii satha.** | The outsider walks in the open. |
| **Kara kiri lishi.** | The predator hides in the canopy. |
| **Owa sulo thalowa.** | The ancestor speaks through the ancestor-bones. |

# Adjectives and Qualities

Qualities usually come **before** the thing they describe.

| Rhulka | Meaning |
| --- | --- |
| **kiri-sii** | hidden trail |
| **raka-sii** | dangerous trail |
| **nhae-nha** | clean water |
| **dulu-rau** | rotten meat |
| **shii-nha** | spirit-water |
| **owa-thal** | remembered bone |
| **rishi-ka** | thorn-bite |

Some qualities can also follow the noun for emphasis.

**Sii kiri.**
“The trail is hidden.”

**Kiri-sii.**
“Hidden trail.”

# Plural and Intensity

Rhulka often uses **repetition** instead of separate plural endings.

| Rhulka | Meaning |
| --- | --- |
| **tik** | small / one small thing |
| **tik-tik** | several small things |
| **trr** | insect / many legs |
| **trr-trr** | swarm-many |
| **saru** | outsider |
| **saru-trr** | many outsiders |
| **thal** | bone |
| **thal-trr** | many bones / massacre |
| **owa** | ancestor / memory |
| **owa-trr** | many ancestors / ancestral multitude |

Repetition can also show urgency, depending on the tone.

| Rhulka | Meaning |
| --- | --- |
| **Kiri.** | Hide. |
| **Kiri-kiri!** | Hide now. |
| **Raka.** | Danger. |
| **Raka-raka!** | Immediate danger. |
| **Trr.** | Insects / swarm. |
| **Trr-trr!** | Swarm coming. |

# Commands

Commands are short. Rhulka drops unnecessary words.

| Rhulka | Meaning |
| --- | --- |
| **Kiri.** | Hide. |
| **Sii.** | Go / follow. |
| **Nha.** | Drink. |
| **Chaka.** | Hunt. |
| **Raka.** | Warn / mark danger. |
| **Sulo.** | Speak / call. |
| **Fii.** | Climb / rise. |
| **Saa.** | Move silently. |
| **Thala.** | Bury / bone the dead. |
| **Hesh.** | Breathe / live. |

A doubled command is urgent.

**Saa-saa.**
“Move silently now.”

# Tense and Time

Rhulka often does not mark tense. Context, gesture, and ritual timing show when something happens.

When needed, use time roots.

| Rhulka | Meaning |
| --- | --- |

| **shaa** | dusk wind |
| **ulu** | night damp |
| **owa** | past / remembered time |
| **niri** | young / future beginning |
| **kik** | soon / sprouting |
| **dulu** | ended / spoiled / too late |

Examples:

| Rhulka | Meaning |

# Common Curses and Insults

Rhulka curses are usually built from images of rot, thirst, broken kinship, bad meat, forgotten ancestors, and the jungle rejecting someone.

Halflings do not curse casually. A curse often marks someone as dangerous, foolish, unclean, or outside the protection of the kin-circle.

| Rhulka | Meaning |
| --- | --- |
| **Dulu-rau!** | Rotten meat! |
| **Nha-na!** | Waterless one! |
| **Na-hu!** | Kinless! |
| **Saru-ka!** | Outsider tooth! |
| **Narra!** | Meat-outsider! |
| **Kaowa-hu!** | Wound-kin / one who harms kin! |
| **Hha-rau!** | Forbidden meat! |
| **Dulu-hesh!** | Rotten breath! |
| **Raka-sii!** | Danger-trail! / cursed path! |
| **Shii-ka!** | Spirit-bite! / cursed by spirits! |
