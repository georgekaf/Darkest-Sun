---

Μερικές φορές ο GM δίνει σε έναν παίκτη ένα luck token για εξαιρετικό roleplaying, ηρωισμό ή απλώς επειδή έκανε κάτι πολύ cool.

Μεγάλες θυσίες, συγκινητικοί λόγοι ή απίστευτα τολμηροί ελιγμοί μπορεί να αξίζουν luck tokens, είτε οι ενέργειες των χαρακτήρων πέτυχαν είτε όχι.

Κάθε παίκτης μπορεί να έχει μόνο ένα luck token τη φορά.

Μπορείς να ξοδέψεις ένα luck token για να ξαναρίξεις οποιαδήποτε ρίψη μόλις έκανες. Πρέπει να κρατήσεις το νέο αποτέλεσμα.

# Hard Luck

Δεν μπορείς να ξοδέψεις luck token σε** critical failures** ή σε μηχανισμούς που παράγουν luck, οπως το bless.

# Give Luck

Μπορείς να δώσεις το luck token σου σε έναν σύντροφο που ειναι near σαν action.
