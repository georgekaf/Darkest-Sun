## Flow Rules

- Acts unlock sequentially — each must be substantially completed before the next
- Hooks within an act can run in any order (Act 5 Hook 2 can run parallel)
- Old quest files (Set 1–6, Final) preserved for backward compatibility
- Each Act page links to the next → follow the arrows above
