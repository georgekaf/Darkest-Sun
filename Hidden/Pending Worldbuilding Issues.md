# Pending Worldbuilding Issues

**GM-only master register of open questions, contradictions and unresolved rulings across all three campaigns.**

## How this file is used

**This file is consulted before, and updated after, every change made anywhere under Darkest Sun** — summaries, session preps, nominees, rules pages, sandbox proposals, and GitHub issues alike.

1. **Before acting**, read this register. If the work touches an entry here, it inherits that entry's status — an open question stays open in the new text, and is not quietly decided by phrasing.
2. **After acting**, update the register: add anything newly discovered, revise anything changed, and move anything answered to *Recently resolved* with the date and the ruling.
3. **If a GitHub issue is filed for an entry, record its number here.** The register is the index; the issue is the workspace. An entry with no issue is not tracked anywhere else.
4. **Resolved entries stay in *Recently resolved* for a while**, then fold into the relevant record and drop off. A resolution that lives only in this file has not been recorded properly.

Status vocabulary: **open** (needs a GM decision) · **held** (decided to leave unresolved on purpose) · **blocked** (waiting on something mechanical, not on a decision) · **resolved**.

## Standing principles

*Rulings by the campaign owner that answer whole classes of question. Apply these before raising a new entry — most schema and "does the book say" questions are already settled here.*

1. **Reachability — everything printed is reachable.** If the book places something where players can go, they can go there. No editorial gating, no "not yet", no holding a reward back for a later power level; the obstacles the book prints are the price, and if the party beats them they have earned it. *(13 August 2026 — established on the Dread Palace's planar gate, restated on Taraskir's Tomb and the +2 dragon slayer.)*
2. **Silence stays silent.** Where the printed source does not answer something, the campaign does not invent an answer. The record carries it as unknown and the table decides what it believes or suspects. *(Templar murder at Akrag's Pools; the graffito in Dregoth's Palace; the estate on Sharg Island; the Happy Hurrum's owner.)*
3. **Split what you travel to, keep what you walk through.** A named place with its own contents, inhabitants or hazards gets its own record, with references **both ways** between parent and child. Rooms inside a single building stay as features of one record. *(Cromlin sub-locations; the eleven Giustenal districts; Akrag's Pools; the Black Tower — against Dregoth's Palace's sixteen rooms, which stay together.)*
4. **Sheet values need no in-world provenance.** Masterwork gear is built by characters themselves with downtime and gold; wild talents explain themselves; ordinary unhealed damage needs no event. *(Ugo, #159.)*

The register has two open sections. **Open — needs a GM decision** holds questions raised by play and by continuity work. **Open — questions carried inside filed MK-Sandbox issues** mirrors the *Unresolved Questions* section of every open issue, so the queue on GitHub and the register never diverge; refresh it from `triage.py` / `issues.cache.json` whenever issues are filed or answered.
